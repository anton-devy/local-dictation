# Contributing

This is an experimental research preview. Open an issue before substantial work so the scope can
be discussed. Submit every change from a branch through a pull request; worktrees are optional.

Behavior, privacy, permission, security, dependency, compatibility, packaging, and release-policy
changes need a complete OpenSpec change in the same PR. Keep implementation, tests, current specs,
README, configuration, and privacy/permission text aligned.

Use the lockfile, run the documented checks, and mock microphones, clipboard, input monitoring,
Automation, desktop UI, and paste injection in automated tests. Do not commit logs, audio from real
people, secrets, or user-specific paths.
